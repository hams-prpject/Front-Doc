مقدمة عن CSS

CSS اختصار لـ Cascading Style Sheets — وهي اللغة التي تُحدد شكل ومظهر صفحات الويب.

HTML يبني هيكل الصفحة (العناوين، الفقرات، الصور)، أما CSS فيُجمّلها ويُحدد ألوانها وخطوطها ومسافاتها.

🏠
تشبيه بسيط

فكّر في HTML كهيكل المنزل (الجدران والأبواب)، وCSS كالديكور والطلاء والأثاث — بدونه المنزل موجود لكنه فارغ ورمادي.

مرحبا بالعالم
✓

CSS لا يحتاج تثبيتاً — يكفي ملف نصي عادي وأي متصفح مثل Chrome أو Firefox!

طرق تضمين CSS

هناك 3 طرق لإضافة CSS إلى صفحتك — لكل طريقة مكانها الصحيح:

1 خارجي الأفضل

ملف .css منفصل مربوط بـ HTML

2 داخلي مقبول

داخل وسم <style> في <head>

3 مضمّن تجنّب

مباشرة بخاصية style في الوسم

1 — الخارجي (style.css)
<link rel="stylesheet" href="style.css">
2 — الداخلي
<style>
  h1 { color: blue; }
</style>
3 — المضمّن
<h1 style="color: blue;">عنوان</h1>
💡

للتعلم: ابدأ بالطريقة الداخلية. للمشاريع الحقيقية: الخارجية دائماً.

CSS Selectors — المحددات

المحدد يخبر المتصفح: "على أيّ عنصر تطبّق هذا الستايل؟"

h1
محدد العنصر
يطبّق الستايل على كل عناصر <h1>
.myClass
محدد الـ Class
يطبّق على كل عنصر يحمل class="myClass"
#myId
محدد الـ ID
يطبّق على عنصر واحد فقط يحمل id="myId"
*
المحدد الشامل
يطبّق على جميع العناصر في الصفحة
/* محدد العنصر */
h1 { color: blue; }

/* محدد الـ class (يبدأ بنقطة) */
.title { font-size: 24px; }

/* محدد الـ id (يبدأ بـ #) */
#logo { width: 100px; }
💡

قاعدة ذهبية: استخدم .class للعناصر المتكررة، و#id للعناصر الفريدة (مرة واحدة فقط في الصفحة).

CSS Comments — التعليقات

التعليقات هي ملاحظات تكتبها لنفسك أو لزملائك.

المتصفح يتجاهلها تماماً — لا تؤثر على شكل الصفحة أبداً.

/* هذا تعليق في CSS */

p {
  color: red; /* اللون الأحمر مؤقت */
  /* font-size: 20px; */  /* سطر معطّل مؤقتاً */
}
📝 استخدام 1

شرح الكود لنفسك أو لمن يعمل معك لاحقاً

🔧 استخدام 2

إيقاف خاصية مؤقتاً لاختبارها دون حذفها

CSS Display — طريقة العرض

خاصية display هي من أهم خصائص CSS — تحدد كيف يظهر العنصر في الصفحة وكيف يتعامل مع العناصر المجاورة.

معاينة تفاعلية — اختر نوع العرض
عنصر 1
عنصر 2
عنصر 3
display: block;
display: block مثل: div, p, h1

يأخذ العنصر كامل عرض الصف — كل عنصر في سطر جديد.

div — يمتد بالكامل
div — سطر جديد
display: inline مثل: span, a, strong

يأخذ العنصر فقط المساحة التي يحتاجها — العناصر تتجاور في نفس السطر.

كلمة كلمة أخرى وكلمة ثالثة
⚠ لا يمكن تحديد width أو height للعناصر inline
display: inline-block الأفضل للأزرار

يجمع ميزتي block و inline — يتجاور مع غيره ويقبل width وheight.

زر 1 زر 2 زر 3
display: none يُخفي العنصر

يُخفي العنصر كلياً — كأنه غير موجود في الصفحة، ولا يحجز مساحة.

عنصر مرئي
[عنصر مخفي — display:none]
عنصر مرئي
display: flex قوي جداً

يجعل العناصر الداخلية تتوزع بشكل مرن — مفيد للتخطيط الأفقي والعمودي.

.container {
  display: flex;
  justify-content: space-between; /* توزيع أفقي */
  align-items: center;          /* محاذاة عمودية */
}
