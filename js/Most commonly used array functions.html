🔄
map()
تحويل كل عنصر → مصفوفة جديدة بنفس الطول
تمرّ على كل عنصر في المصفوفة، تُطبّق عليه دالة، وتُعيد مصفوفة جديدة تماماً. المصفوفة الأصلية لا تتغير أبداً. مثالية لتحويل البيانات وتهيئتها لعرضها.
// مثال — تحويل أسعار من دولار إلى شيكل
const pricesInDollars = [10, 20, 50, 100];

const pricesInShekels = pricesInDollars.map(price => price * 3.7);

console.log(pricesInShekels);
// النتيجة: [37, 74, 185, 370]

console.log(pricesInDollars);
// الأصل لم يتغير: [10, 20, 50, 100]

filter()
تصفية العناصر حسب شرط → مصفوفة أصغر أو تساوي
تمرّ على كل عنصر وتختبر عليه شرطاً (true/false). العناصر التي تُعيد true تنتقل للمصفوفة الجديدة، والباقي يُستبعد. المصفوفة الأصلية لا تتغير.
// مثال — تصفية المستخدمين البالغين
const users = [
  { name: "Ahmed", age: 15 },
  { name: "Sara",  age: 22 },
  { name: "Ali",   age: 30 }
];

const adults = users.filter(user => user.age >= 18);

console.log(adults);
// [{ name: "Sara", age: 22 }, { name: "Ali", age: 30 }]
⚡ جرّب — غيّر حد العمر
المستخدمون المُصفَّون
اضغط تصفية لرؤية النتيجة

find()
أول عنصر يحقق الشرط → يتوقف فور العثور عليه
تبحث عن أول عنصر واحد فقط يحقق الشرط ثم تتوقف فوراً (أكثر كفاءة من filter عند البحث عن عنصر واحد). إن لم تجد شيئاً تُعيد undefined.
// مثال — البحث عن منتج بالـ ID
const products = [
  { id: 1, title: "Laptop",  price: 1200 },
  { id: 2, title: "Phone",   price: 800  },
  { id: 3, title: "Tablet",  price: 500  }
];

const found = products.find(p => p.id === 2);

console.log(found.title);
// "Phone"

reduce()
تلخيص المصفوفة كلها → قيمة واحدة
الأقوى والأكثر مرونة. تمرّ على كل عنصر وتبني قيمة تراكمية (accumulator). تبدأ من قيمة ابتدائية وتُضيف إليها مع كل خطوة. نتيجتها قيمة واحدة: عدد، نص، كائن، أو أي شيء.
// مثال — إجمالي سلة التسوق
const cart = [100, 250, 50];

const total = cart.reduce((accumulator, currentPrice) => {
  return accumulator + currentPrice;
}, 0); // ← الصفر: القيمة الابتدائية

// الخطوات:
// acc=0   + 100 = 100
// acc=100 + 250 = 350
// acc=350 + 50  = 400 ✓

console.log(total); // 400

slice() مقابل splice()
الفرق الجوهري الذي يجب أن تعرفه
slice(start, end)

تأخذ نسخة من المصفوفة من موضع start حتى end (غير شامل). المصفوفة الأصلية تبقى سليمة تماماً.

✓ آمنة — لا تعدّل الأصل
splice(index, count)

تحذف عناصر مباشرة من المصفوفة الأصلية ابتداءً من موضع index. يمكن أيضاً إضافة عناصر مكانها.

⚠ مدمّرة — تعدّل الأصل
// مثال مقارن
let fruits = ["Apple", "Banana", "Orange", "Mango"];

// slice — آمن
let some = fruits.slice(1, 3);
console.log(some);   // ["Banana", "Orange"]
console.log(fruits); // لا يزال 4 عناصر ✓

// splice — مدمّر
fruits.splice(0, 1);
console.log(fruits); // ["Banana","Orange","Mango"] — Apple اختفى!

دليلك لاختيار الدالة المناسبة في ثانية واحدة

العملية المطلوبة الدالة تعدّل الأصل؟ تُعيد
تحويل كل عنصر map() لا ✓ مصفوفة جديدة (نفس الطول)
تصفية بشرط filter() لا ✓ مصفوفة جديدة (أصغر أو تساوي)
البحث عن عنصر واحد find() لا ✓ العنصر أو undefined
حساب مجموع / إجمالي reduce() لا ✓ قيمة واحدة (أي نوع)
نسخ جزء من المصفوفة slice() لا ✓ مصفوفة جديدة
حذف / إضافة في مكان معين splice() نعم ⚠ العناصر المحذوفة
إضافة للنهاية push() نعم ⚠ الطول الجديد
التأكد من وجود قيمة includes() لا ✓ true / false
