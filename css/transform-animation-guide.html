لماذا نتعلّم Transform و Animation؟

الواجهات الجامدة تُمَلّ المستخدم. عندما يحرّك الزائر مؤشّر الفأرة فوق زرٍّ ولا يتغيّر شيء، يشعر أنّ الموقع ميّت. أمّا عندما يكبر الزر قليلاً أو يتغيّر لونه بسلاسة، يشعر بأنّ الموقع يتجاوب معه.

الـ Transform هو ما يسمح لنا بتحويل العنصر — تحريكه، تكبيره، تدويره، إمالته. والـ Animation هو ما يجعل هذا التحويل يحدث على مدى زمنٍ معيّن وبسلاسة.

الفرق بينهما باختصار:
  • • Transform = ماذا يحدث للعنصر (الشكل النهائي)
  • • Transition = تحوّلٌ سلس عند تغيير حالة (مثل hover)
  • • Animation = حركة مستمرة بعدة مراحل (keyframes)

سنبدأ بـ Transform أولاً، لأنه الأساس. ثم نستخدمه داخل Animation لخلق حركاتٍ ساحرة.

خصائص Transform

خاصية واحدة (transform) تستقبل عدة دوال للتحويل. لنرَ أهمها:

١translate — التحريك

ينقل العنصر من مكانه دون التأثير على بقيّة العناصر حوله.

CSS
/* تحريك أفقي (يميناً موجب، يساراً سالب) */
transform: translateX(50px);

/* تحريك رأسي (للأسفل موجب، للأعلى سالب) */
transform: translateY(-20px);

/* في الاتجاهين معاً */
transform: translate(50px, -20px);

جرّب: مرّر الفأرة فوق الصندوق

→

translateX(80px) — تحريك يمين 80px

سؤال شائع: ما الفرق بين translate و margin؟
الـ margin يُزيح العناصر المجاورة. أمّا translate ينقل العنصر بصرياً فقط دون التأثير على غيره — ولذلك هو أسرع وأنعم في الحركات.

٢rotate — التدوير

يدوّر العنصر حول مركزه بزاوية معيّنة.

CSS
/* بالدرجات (الأكثر استخداماً) */
transform: rotate(45deg);

/* قيمة سالبة = عكس عقارب الساعة */
transform: rotate(-30deg);

/* دورة كاملة */
transform: rotate(360deg);
↻

rotate(45deg)

↻

rotate(360deg) — دورة كاملة

٣scale — التكبير والتصغير

يكبّر العنصر أو يصغّره. القيمة 1 تعني الحجم الطبيعي، أكبر من 1 تكبير، وأقل من 1 تصغير.

CSS
/* تكبير 1.5 ضعف */
transform: scale(1.5);

/* تصغير للنصف */
transform: scale(0.5);

/* تكبير الأفقي فقط */
transform: scaleX(2);

/* تكبير الرأسي فقط */
transform: scaleY(2);

/* تكبير مختلف للاتجاهين */
transform: scale(1.2, 0.8);
+

scale(1.5) — تكبير

−

scale(0.5) — تصغير

٤skew — الإمالة

يميل العنصر بزاوية معيّنة، كأنّك تنظر إليه من جانب.

CSS
transform: skewX(20deg);    /* إمالة أفقية */
transform: skewY(10deg);    /* إمالة رأسية */
transform: skew(20deg, 5deg);
▱

skewX(20deg)

٥دمج عدة تحويلات معاً

يمكنك تطبيق أكثر من تحويل في نفس الوقت — فقط افصل بينها بمسافة.

CSS
transform: translateX(60px) rotate(180deg) scale(1.2);
⚠️ تنبيه مهم: الترتيب يهم!
translate(50px) rotate(45deg) ≠ rotate(45deg) translate(50px)
في الأولى يتحرّك ثم يدور في مكانه. في الثانية يدور أولاً ثم يتحرّك في الاتجاه الجديد.
★

translateX(60px) rotate(180deg) scale(1.2)

٦transform-origin — نقطة الارتكاز

افتراضياً يدور العنصر حول مركزه. لكن يمكنك تغيير نقطة الارتكاز:

CSS
transform-origin: center;       /* الافتراضي */
transform-origin: top left;     /* الزاوية اليسرى العلوية */
transform-origin: 0 0;             /* نفس الأعلى يسار */
transform-origin: 100% 50%;        /* الجانب الأيمن */

Transition — التحوّل السلس

لاحظت أن أمثلة Transform السابقة كانت تنتقل بسلاسة عند الـ hover، لا بقفزة فجائية. السبب: استخدمنا transition.

الـ Transition يقول للمتصفح: "إذا تغيّرت قيمة هذه الخاصية، لا تنفّذ التغيير فوراً، بل انتقل إليه تدريجياً خلال زمن معيّن".

CSS
.box {
  background: red;
  transition: background 0.5s ease;
}
.box:hover {
  background: blue;  /* سينتقل من أحمر لأزرق خلال نصف ثانية */
}

صيغة transition الكاملة:

transition: [الخاصية] [المدة] [الدالة الزمنية] [التأخير];

transition: transform 0.3s ease-out 0.1s;

/* لجميع الخصائص دفعة واحدة */
transition: all 0.3s ease;

/* عدة خصائص بقيم مختلفة */
transition:
  transform 0.3s ease,
  background 0.5s linear;

الدوال الزمنية (Timing Functions):

تحدّد كيف يحدث الانتقال — هل يبدأ سريعاً ثم يبطئ؟ أم العكس؟ شاهد الفروق:

linearسرعة ثابتة
easeالافتراضي — بداية بطيئة، تسارع، نهاية بطيئة
ease-inيبدأ بطيء ويسرع
ease-outيبدأ سريع ويبطئ — الأفضل للـ UI
cubic-bezier(0.68, -0.55, 0.27, 1.55)ارتدادي — للحركات المرحة
قاعدة ذهبية: استخدم ease-out للأشياء التي تظهر، و ease-in للأشياء التي تختفي. هذا يعطي شعوراً طبيعياً بالحركة.

الجزء الثالث · ٠٤

Animation و @keyframes

الـ Transition يحتاج محفّزاً (مثل hover) لكي يعمل. لكن ماذا لو أردتَ حركةً دائمة (مثل دوران مؤشّر التحميل)؟

هنا يأتي دور @keyframes + animation.

١تعريف الحركة بـ @keyframes

أولاً نُعرّف "مراحل" الحركة (المفاتيح). كل مرحلة تحدّد كيف يبدو العنصر عند نسبة معيّنة من الحركة.

CSS
/* الصيغة المختصرة: مرحلتين فقط */
@keyframes spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}

/* الصيغة الكاملة: مراحل متعددة بنسب مئوية */
@keyframes bounce {
  0%   { transform: translateY(0); }
  50%  { transform: translateY(-30px); }
  100% { transform: translateY(0); }
}

٢تطبيق الحركة بـ animation

بعد تعريف الـ keyframes، نطبّقها على العنصر:

CSS
.loader {
  animation: spin 1s linear infinite;
}

/* مفصّلة */
.loader {
  animation-name:            spin;
  animation-duration:        1s;
  animation-timing-function: linear;
  animation-iteration-count: infinite;
  animation-delay:           0.5s;
  animation-direction:       alternate;
  animation-fill-mode:       forwards;
}

٤الخصائص الفرعية للـ animation

animation-iteration-count

عدد مرات تكرار الحركة. 3 أو infinite للتكرار اللانهائي.

animation-direction

normal · reverse · alternate (ذهاب وعودة).

animation-delay

تأخير قبل بدء الحركة. مفيد لتسلسل عدة عناصر.

animation-fill-mode

forwards = ابقَ في النهاية. backwards = ابدأ من البداية قبل الـ delay.

المهمة العملية

🎯 المطلوب:

صمّم بطاقة منتج تفاعلية لمتجر إلكتروني، تحتوي على:

  • • صورة (أو emoji) في الأعلى تكبر بـ scale(1.1) عند hover على البطاقة
  • • البطاقة كلها ترتفع 8px للأعلى عند hover
  • • زر "أضف للسلة" يهتزّ (shake) عند الضغط
  • • شارة "خصم" تنبض باستمرار (animation pulse)
  • • عند تحميل الصفحة، البطاقة تظهر بانزلاق من الأسفل

تلميح: استخدم transition للتفاعلات (hover/active) و @keyframes للحركات المستمرة.

📋 الخطوات المقترحة:

  1. أنشئ HTML بسيطاً للبطاقة: صورة، عنوان، سعر، شارة، زر
  2. أضف transition: all 0.3s ease على البطاقة والصورة
  3. طبّق transform داخل :hover
  4. عرّف @keyframes pulse للشارة
  5. عرّف @keyframes shake وطبّقه في :active للزر
  6. عرّف @keyframes slideUp وطبّقه على البطاقة عند التحميل
معايير التقييم: الحركات سلسة (مدة بين 0.2s و 0.6s)، التحويلات لا تؤثر على بقيّة العناصر، الكود نظيف ومنظم، الـ keyframes معرّفة في مكان واحد.

أسئلة سريعة

س١: ما الفرق الأساسي بين transition و animation؟

animation أسرع من transition
transition يحتاج محفّزاً (hover مثلاً)، animation يعمل تلقائياً ويدعم مراحل متعددة
transition يعمل فقط على الألوان

س٢: ماذا يفعل transform: scale(0.5)؟

يدوّر العنصر بـ 0.5 درجة
يصغّر العنصر للنصف
يحرّك العنصر 50px

س٣: ما معنى animation-iteration-count: infinite؟

الحركة تنتهي بسرعة لانهائية
الحركة تتكرر بلا توقّف
الحركة تشتغل مرة واحدة فقط

س٤: أي دالة زمنية تجعل الحركة تبدأ سريعة وتنتهي ببطء؟

linear
ease-in
ease-out

س٥: أيّهما يؤثر على بقيّة العناصر المجاورة؟

transform: translateX(50px)
margin-left: 50px
كلاهما لا يؤثر

س٦: داخل @keyframes ماذا يعني 50%؟

الحركة تنفّذ بنصف سرعتها
منتصف مدّة الحركة الزمنية
العنصر يُصغَّر للنصف

ورقة المرجع السريعة

/* ═══ TRANSFORM ═══ */
transform: translateX(50px);          /* تحريك */
transform: translateY(-20px);
transform: rotate(45deg);             /* تدوير */
transform: scale(1.5);                /* تكبير */
transform: scale(0.5);                /* تصغير */
transform: skewX(20deg);              /* إمالة */

/* الدمج (الترتيب يهم!) */
transform: translateX(50px) rotate(180deg) scale(1.2);

transform-origin: center;             /* نقطة الارتكاز */

/* ═══ TRANSITION ═══ */
transition: transform 0.3s ease;
transition: all 0.3s ease-out;
transition:
  transform   0.3s ease,
  background  0.5s linear;

/* ═══ ANIMATION ═══ */
@keyframes myAnim {
  from { transform: scale(1); }
  to   { transform: scale(1.2); }
}

@keyframes complex {
  0%   { opacity: 0;  transform: translateY(20px); }
  50%  { opacity: 0.5; }
  100% { opacity: 1;  transform: translateY(0); }
}

.element {
  animation: myAnim 1s ease-in-out infinite alternate;
}

/* خصائص مفصّلة */
animation-name: myAnim;
animation-duration: 1s;
animation-timing-function: ease-out;
animation-iteration-count: infinite;  /* أو رقم */
animation-delay: 0.5s;
animation-direction: alternate;       /* normal | reverse | alternate */
animation-fill-mode: forwards;        /* forwards | backwards | both */
