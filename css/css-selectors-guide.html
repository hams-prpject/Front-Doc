01

المُحدِّدات الأساسية

أبسط طرق اختيار العناصر: عن طريق اسم الوسم، أو الكلاس، أو الـ ID، أو اختيار كل شيء دفعة واحدة.

*

Universal Selector — يختار كل عنصر في الصفحة بدون استثناء.

* { margin: 0; }
النتيجة
divpspana
p

Type / Element Selector — يختار كل عناصر من نفس نوع الوسم (tag name).

p { color: teal; }
النتيجة
<p><p><div>
.card

Class Selector — يختار كل عنصر يحمل هذا الاسم في خاصية class، ويمكن تكرار نفس الكلاس على عناصر متعددة.

.card { border: 1px solid #ccc; }
النتيجة
class="card"class="card active"class="item"
#header

ID Selector — يختار عنصرًا واحدًا فقط بمعرّف فريد (id). يجب ألا يتكرر الـ id في نفس الصفحة.

#header { position: sticky; }
النتيجة
id="header"id="footer"
02

التجميع (Grouping)

تطبيق نفس القواعد على أكثر من محدِّد دفعة واحدة، بالفصل بينها بفاصلة.

h1, h2, h3

يطبّق نفس التنسيق على كل العناصر المذكورة، بغضّ النظر عن نوعها.

h1, h2, h3 {
  font-family: Tajawal;
}
النتيجة
<h1><h2><h3><p>
.btn, #cta, a

يمكن خلط أي نوع محدِّدات معًا (class + id + tag) في نفس التجميع.

.btn, #cta, a {
  cursor: pointer;
}
03

المُجمِّعات (Combinators)

تربط بين محدِّدين لاختيار عنصر بناءً على علاقته بعنصر آخر داخل الشجرة (parent / child / sibling).

div p

Descendant Combinator (مسافة) — يختار كل <p> داخل <div> بغض النظر عن عمق التداخل.

div p { color: gray; }
شجرة العناصر
  • div
    • p
    • section
      • p (متداخل)
div > p

Child Combinator — يختار فقط <p> التي هي ابن مباشر لـ <div>، وليس أي حفيد أعمق.

div > p { color: crimson; }
شجرة العناصر
  • div
    • p (ابن مباشر)
    • section
      • p (حفيد – غير مطابق)
h2 + p

Adjacent Sibling — يختار العنصر الذي يأتي مباشرة بعد شقيقه، وله نفس الأب.

h2 + p { margin-top: 0; }
النتيجة
h2p (مباشرة بعده)p (الثاني – غير مطابق)
h2 ~ p

General Sibling — يختار كل الأشقاء اللاحقين من نفس النوع، وليس فقط المجاور مباشرة.

h2 ~ p { color: slateblue; }
النتيجة

04

محدِّدات السمات (Attribute Selectors)

تختار العناصر بناءً على وجود سمة (attribute) أو قيمتها أو جزء منها.

[disabled]

يختار أي عنصر يحمل هذه السمة، بغضّ النظر عن قيمتها.

[disabled] { opacity: .5; }
<button disabled>
<button>
[type="text"]

يختار العنصر عندما تساوي قيمة السمة النص بالضبط (تطابق تام).

[type="text"] { border: 1px solid #444; }
type="text"
type="email"
[class~="tag"]

تطابق كلمة كاملة ضمن قائمة قيم مفصولة بمسافات (مثل خاصية class المتعددة).

[class~="new"] { color: gold; }
class="item new"
class="renewal"
[lang|="en"]

تطابق القيمة بالضبط أو القيمة متبوعة بشرطة (-)، شائع في سمات اللغة.

[lang|="en"] { direction: ltr; }
lang="en-US"
lang="ar"
[href^="https"]

Starts With — تطابق القيم التي تبدأ بالنص المحدَّد.

[href^="https"] { color: green; }
href="https://a.com"
href="ftp://a.com"
[src$=".png"]

Ends With — تطابق القيم التي تنتهي بالنص المحدَّد.

[src$=".png"] { border-radius: 8px; }
src="logo.png"
src="logo.jpg"
[title*="css"]

Contains — تطابق القيم التي تحتوي على النص في أي مكان منها.

[title*="css"] { outline: 1px dashed; }
title="learn-css-fast"
title="learn-html"
[data-x="1" i]

اللاحقة i تجعل المطابقة غير حساسة لحالة الأحرف (case-insensitive).

[data-x="yes" i] { }
data-x="YES"
data-x="yes"
05

Pseudo-classes

تختار العناصر بناءً على حالتها أو موقعها ضمن الشجرة، وليس بناءً على اسمها أو سماتها. تبدأ دائمًا بنقطتين ( : ).

حالات التفاعل

:hover

عند تمرير الفأرة فوق العنصر.

a:hover { color: orange; }
:focus

عند وضع التركيز على العنصر (مثل حقل إدخال).

input:focus { outline: 2px solid blue; }
:active

أثناء لحظة الضغط على العنصر.

button:active { transform: scale(.97); }
:visited

الروابط التي زارها المستخدم من قبل.

a:visited { color: purple; }
:link

الروابط التي لم تُزَر بعد.

a:link { color: blue; }

الموقع البنيوي (Structural)

:first-child

العنصر إذا كان الابن الأول لأبيه.

li:first-child { }
  • li
  • li
  • li
:last-child

العنصر إذا كان الابن الأخير لأبيه.

li:last-child { }
  • li
  • li
  • li
:only-child

العنصر إذا كان الابن الوحيد لأبيه.

p:only-child { }
:nth-child(n)

يختار الأبناء حسب ترتيبهم الرقمي؛ يقبل صيغًا مثل 2n (زوجي) أو 2n+1 (فردي) أو رقم ثابت.

li:nth-child(2n) { }  /* زوجي */
  • 1
  • 2
  • 3
  • 4
:nth-last-child(n)

نفس الفكرة، لكن العدّ يبدأ من آخر عنصر.

li:nth-last-child(1) { }
:first-of-type

أول عنصر من نفس نوع الوسم بين إخوته (حتى لو لم يكن أول ابن مطلقًا).

p:first-of-type { }
:last-of-type

آخر عنصر من نفس نوع الوسم بين إخوته.

p:last-of-type { }
:nth-of-type(n)

يختار حسب الترتيب، لكن بالعدّ فقط بين العناصر من نفس النوع.

img:nth-of-type(3) { }
:only-of-type

العنصر الوحيد من نوعه بين إخوته.

span:only-of-type { }
:empty

العنصر الذي لا يحتوي أي محتوى ولا عناصر ابنة (حتى نص أو مسافة).

div:empty { display: none; }
:root

يشير إلى العنصر الجذر في المستند (<html>)، يُستخدم غالبًا لتعريف متغيرات CSS.

:root { --main-color: #333; }

النماذج (Forms)

:checked

مربعات الاختيار أو الأزرار الدائرية المُفعَّلة.

input:checked { }
:disabled

عناصر النموذج المُعطَّلة.

input:disabled { }
:enabled

عناصر النموذج النشطة (غير معطّلة).

input:enabled { }
:required

حقول الإدخال الإلزامية.

input:required { }
:optional

حقول الإدخال الاختيارية.

input:optional { }
:valid / :invalid

حسب صحة القيمة المُدخلة وفق قواعد التحقق.

input:invalid { border-color: red; }
:placeholder-shown

الحقل الذي ما زال يعرض نص placeholder (لم يُكتب فيه شيء).

input:placeholder-shown { }

منطقية ومتقدّمة

:not(selector)

يختار كل عنصر لا يطابق المُحدِّد الموجود بداخله.

li:not(.active) { opacity: .6; }
:is(selector-list)

اختصار لتجميع عدّة محدِّدات معًا، ويأخذ أولوية أعلى محدِّد بداخله.

:is(h1, h2, h3) { }
:where(selector-list)

مثل :is() تمامًا في الوظيفة، لكن أولويته (specificity) دائمًا صفر.

:where(h1, h2, h3) { }
:has(selector)

يختار العنصر الأب إذا كان يحتوي على العنصر المذكور بداخله (relational selector).

div:has(> img) { border: 1px solid; }
:target

العنصر الذي يطابق الـ id الموجود في الرابط الحالي (hash في الـ URL).

#section:target { background: yellow; }
:lang(ar)

العناصر المكتوبة بلغة معيّنة حسب سمة lang.

:lang(ar) { direction: rtl; }
06

Pseudo-elements

تنشئ أو تختار جزءًا محدَّدًا داخل العنصر (وليس العنصر نفسه)، وتبدأ بنقطتين مزدوجتين ( :: ).

::before

يُضيف محتوى وهميًا قبل محتوى العنصر الفعلي، يتطلّب خاصية content.

.tag::before { content: "# "; }
::after

يُضيف محتوى وهميًا بعد محتوى العنصر الفعلي.

.tag::after { content: " ✓"; }
::first-letter

يستهدف أوّل حرف فقط من نص العنصر.

p::first-letter { font-size: 2em; }
::first-line

يستهدف أوّل سطر مرئي فقط من نص العنصر.

p::first-line { font-weight: bold; }
::selection

يُنسِّق الجزء الذي يُحدِّده المستخدم بالفأرة (تحديد النص).

::selection { background: #f4b93e; }
::placeholder

يُنسِّق النص الإرشادي داخل حقول الإدخال.

input::placeholder { color: #999; }
::marker

يُنسِّق علامة العنصر في القوائم (النقطة أو الرقم).

li::marker { color: crimson; }
::backdrop

الطبقة الخلفية التي تظهر خلف عناصر مثل <dialog> أو العناصر في وضع ملء الشاشة.

dialog::backdrop { background: rgba(0,0,0,.6); }
07

ترتيب الأولوية (Specificity)

عند تعارض أكثر من قاعدة على نفس العنصر، يفوز المحدِّد الأعلى أولوية. الترتيب من الأضعف إلى الأقوى:

Levelالنوعمثال
0عام (Universal) / التجميع لا يُضيف أولوية*
1الوسم + Pseudo-elementsdiv ، ::before
2الكلاس + السمات + Pseudo-classes.card ، [type] ، :hover
3الـ ID#header
4Inline stylestyle="..."
∞مع !important — تتجاوز كل ما سبقcolor: red !important;
