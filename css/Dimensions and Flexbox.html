CSS Min/Max Height and Width

خصائص التحكم في الحدود الدنيا والعليا للأبعاد

Min-Width و Min-Height

تضمن أن العنصر لا يصغر عن حجم معين:

min-width: 300px; min-height: 200px;
min-width: 300px
لن ينكمش هذا العنصر عن 300px حتى لو صغرت الشاشة
أفضل ممارسة

استخدم min-width للأزرار والصور لضمان قابلية النقر والعرض.

Max-Width و Max-Height

تحدد الحد الأقصى لحجم العنصر:

max-width: /* أقصى عرض */ max-height: 400px; /* أقصى ارتفاع */
max-width: 400px
سينكمش هذا العنصر إذا صغرت الشاشة، ولن يتجاوز 400px
نصيحة

استخدم max-width: 100% للصور لمنعها من تجاوز حاويتها.

جدول مقارنة الخصائص

الخاصية الوصف أفضل استخدام
width/height أبعاد ثابتة عناصر ذات حجم ثابت معروف
min-width/min-height أقل حد مسموح ضمان حجم أدنى للأزرار والصور
max-width/max-height أقصى حد مسموح منع العناصر من الكبر الزائد

CSS Flexbox

نظام التخطيط المرن - أداة قوية لتوزيع العناصر

ماهو Flexbox؟

Flexbox (Flexible Box Layout) هو نظام تخطيط أحادي الأبعاد يسمح لك بترتيب العناصر وتوزيعها داخل حاوية بطريقة متجاوبة وسهلة.

مميزات Flexbox
  • توزيع المسافات بين العناصر تلقائياً
  • محاذاة العناصر أفقياً وعمودياً بسهولة
  • تعديل ترتيب العناصر دون تغيير HTML
  • إنشاء تخطيطات متجاوبة بسرعة
/* تفعيل Flexbox */ .container { display: flex; }
