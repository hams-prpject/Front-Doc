المقدمة · ٠١

ما هو CSS Grid؟

الـ CSS Grid نظامُ تخطيطٍ ثنائي الأبعاد، يعني أنه يتعامل مع الصفوف والأعمدة معاً في الوقت ذاته. وهذا ما يميّزه عن نظام Flexbox الذي يعمل في بُعدٍ واحدٍ فقط (إما صفّ أو عمود).

تخيّل أنك تريد رسم جدولٍ على ورقة: تحدّد عدد الأعمدة، عدد الصفوف، ثم تضع كل عنصرٍ في خانته المناسبة. هذا بالضبط ما يفعله Grid في صفحة الويب — لكن بمرونةٍ أكبر بكثير.

متى تستخدم Grid؟ عندما تحتاج إلى تخطيطٍ ثنائي الأبعاد (شبكة معارض الصور، لوحات التحكم، تصميمات المجلات). أمّا للقوائم والأشرطة الأفقية البسيطة فاستخدم Flexbox.

المفاهيم الأساسية

قبل أن نبدأ، يجب أن نتفق على هذه المصطلحات:

📦

الحاوية (Grid Container)

هي العنصر الأب الذي نطبّق عليه display: grid. كل العناصر داخلها تصبح عناصرَ شبكية.

🧱

العنصر (Grid Item)

هو كل عنصرٍ مباشرٍ داخل الحاوية. لا تحتاج إلى إعدادٍ إضافي — يصبح Grid Item تلقائياً.

📏

الخطوط (Grid Lines)

الخطوط التي تفصل بين الأعمدة والصفوف. ترقّم من 1 ابتداءً (أو -1 من النهاية).

خصائص الحاوية · ٠٣

خصائصُ الحاوية الأساسية

١display: grid

الخطوة الأولى دائماً. بدونها لا يوجد Grid أصلاً.

CSS
.container {
  display: grid;
}

٢grid-template-columns

تحدّد عدد الأعمدة وعرض كل عمود. هذه الخاصية هي قلب Grid — لن تستغني عنها.

CSS
/* ٣ أعمدة بأحجام ثابتة */
grid-template-columns: 200px 200px 200px;

/* ٣ أعمدة متساوية بنسب */
grid-template-columns: 1fr 1fr 1fr;

/* اختصار باستخدام repeat */
grid-template-columns: repeat(3, 1fr);

/* أعمدة مختلطة: ثابت + مرن */
grid-template-columns: 200px 1fr 100px;
ما هو الـ fr؟ اختصار لـ fraction (كسر). هو وحدة مرنة تأخذ من المساحة المتبقية. مثلاً 1fr 2fr يعني العمود الثاني ضعف الأول.

مثال عملي:

1fr
2fr
1fr

٣grid-template-rows

نفس فكرة الأعمدة، لكن للصفوف.

CSS
grid-template-rows: 100px 200px 100px;

/* مع الأعمدة معاً */
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: 80px 200px;
}

٤gap (المسافات)

تحدّد المسافة بين العناصر. أبسط طريقة وأكثرها استخداماً.

CSS
/* مسافة موحدة */
gap: 20px;

/* صفوف 20px وأعمدة 10px */
gap: 20px 10px;

/* تحكّم منفصل */
row-gap: 20px;
column-gap: 10px;

٥repeat() مع auto-fit و minmax()

من أقوى الميزات في Grid. تجعل التخطيط متجاوباً تلقائياً بدون media queries!

CSS
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

الترجمة: أنشئ أعمدةً تلقائياً، كل عمود لا يقلّ عن 200px وإذا توفّرت مساحة فليأخذ الباقي بالتساوي. عند تصغير الشاشة تنتقل العناصر للسطر التالي تلقائياً.

٦المحاذاة (Alignment)

للتحكم بمحاذاة العناصر داخل الحاوية.

justify-items

محاذاة أفقية لكل عنصر داخل خليّته (start / center / end / stretch)

align-items

محاذاة رأسية لكل عنصر داخل خليّته

justify-content

محاذاة الشبكة كلّها أفقياً داخل الحاوية

align-content

محاذاة الشبكة كلّها رأسياً داخل الحاوية

الاختصار الذهبي: place-items: center يطبّق justify-items و align-items معاً — لتوسيط أي شيء في وسط أي شيء بسطرٍ واحد!

خصائص العناصر · ٠٤

خصائصُ العناصر داخل الشبكة

حتى الآن طبّقنا الخصائص على الحاوية. لكن أحياناً نريد أن يأخذ عنصرٌ معيّنٌ مساحةً أكبر، أو يبدأ من خانةٍ معيّنة. هنا تأتي خصائص العناصر.

١grid-column

يحدّد بأي خط يبدأ العنصر وبأي خط ينتهي أفقياً.

CSS
/* يبدأ من الخط 1 وينتهي عند الخط 3 (يأخذ عمودين) */
.item {
  grid-column: 1 / 3;
}

/* اختصار باستخدام span (يأخذ عمودين من حيث ما بدأ) */
.item {
  grid-column: span 2;
}

/* من البداية إلى النهاية (طول الصف كله) */
.item {
  grid-column: 1 / -1;
}

مثال — العنصر الأول يأخذ عمودين:

٢grid-row

نفس فكرة grid-column لكن للصفوف.

CSS
.item {
  grid-row: 1 / 3;        /* يأخذ صفّين */
  grid-row: span 2;       /* اختصار */
}

٣grid-area

اختصار يجمع الصف والعمود في سطرٍ واحد.

CSS
/* row-start / column-start / row-end / column-end */
.item {
  grid-area: 1 / 1 / 3 / 3;
}

تمرينٌ تطبيقي · ٠٧

المهمة العملية

🎯 المطلوب:

صمّم صفحة بطاقات منتجات لمتجر إلكتروني. الصفحة تحتوي على:

  • • هيدر يمتد على كامل عرض الصفحة (يأخذ كل الأعمدة)
  • • قائمة جانبية ثابتة بعرض 240px
  • • منطقة منتجات فيها 6 بطاقات على الأقل
  • • البطاقات تتكيّف مع حجم الشاشة (auto-fit + minmax)
  • • المنتج المميّز يأخذ عمودين
  • • فوتر في الأسفل يمتد بعرض الصفحة

تلميح: كل ما تحتاجه موجود في هذا الدرس. ابدأ بالحاوية الكبرى ثم اعمل من الخارج إلى الداخل.

📋 الخطوات المقترحة:

  1. أنشئ ملف HTML مع البنية الأساسية (header, aside, main, footer)
  2. طبّق display: grid على body
  3. حدّد grid-template-columns: 240px 1fr
  4. اجعل header و footer يمتدّان بـ grid-column: 1 / -1
  5. داخل main، أنشئ شبكة جديدة للبطاقات بـ repeat(auto-fit, minmax(200px, 1fr))
  6. اجعل البطاقة الأولى مميّزة بـ grid-column: span 2
معايير التقييم: الصفحة تعمل بدون media queries، البطاقات تنتقل تلقائياً عند تصغير الشاشة، التخطيط نظيف وغير متداخل.

أسئلة سريعة

س١: ما الفرق الأساسي بين Grid و Flexbox؟

Grid أسرع من Flexbox
Grid ثنائي الأبعاد (صفوف وأعمدة)، Flexbox أحادي البُعد
Flexbox لا يدعم المتصفحات القديمة

س٢: ماذا يفعل repeat(auto-fit, minmax(200px, 1fr))؟

يكرّر العمود 200 مرة
ينشئ عموداً واحداً متوسطه 200px
ينشئ أعمدة بأقل عرض 200px وتتكيّف تلقائياً مع الشاشة

س٣: كيف تجعل عنصراً يأخذ عمودين؟

width: 200%
grid-column: span 2
grid-cols: 2

س٤: ما معنى وحدة 1fr؟

1 frame
1 fraction — كسر من المساحة المتبقية
1 pixel

س٥: ماذا يعني grid-column: 1 / -1؟

لا يأخذ أي عمود
يأخذ أول عمود فقط
يمتد من أول عمود إلى آخر عمود (كامل العرض)
الخلاصة · ٠٩

ورقة المرجع السريعة

/* ═══ الحاوية ═══ */
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: auto;
  gap: 16px;
  place-items: center;        /* محاذاة العناصر */
}

/* ═══ تخطيط متجاوب ═══ */
.responsive {
  grid-template-columns:
    repeat(auto-fit, minmax(200px, 1fr));
}

/* ═══ العناصر ═══ */
.item-wide   { grid-column: span 2; }
.item-tall   { grid-row: span 2; }
.item-corner { grid-area: 1 / 1 / 3 / 3; }
.full-width  { grid-column: 1 / -1; }
