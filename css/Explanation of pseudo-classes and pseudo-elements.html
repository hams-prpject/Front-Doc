CSS Selectors

شرح الـPseudo-classes والـPseudo-elements

ملخص عملي منظم يوضح التعريف، وطريقة الكتابة، والفرق بين المحددات، مع أمثلة يمكن تجربتها مباشرة داخل الصفحة.

00

الفرق الأساسي

Pseudo-class

تصف حالة العنصر أو موقعه بين العناصر، وتكتب بنقطتين واحدة.

selector:pseudo-class

مثال: button:hover

Pseudo-element

يستهدف جزءًا افتراضيًا من العنصر أو يضيف جزءًا تجميليًا دون كتابة عنصر HTML جديد.

selector::pseudo-element

مثال: p::first-letter

فهرس الشرح

حالات التفاعل محددات البنية والترتيب محددات النماذج المحددات المنطقية والروابط العناصر الزائفة
أولًا

حالات التفاعل والتركيز

محددات تعمل حسب تفاعل المستخدم مع العنصر.

1

:hover

تعمل عندما يمر مؤشر الماوس فوق العنصر.

جرّب: مرّر الماوس فوق الزر.

عرض الكود 
.hover-button:hover {
  background-color: #2563eb;
  transform: translateY(-3px);
}
2

:focus

تعمل عندما يحصل العنصر على التركيز، مثل الضغط داخل حقل إدخال.

جرّب: اضغط داخل الحقل.

عرض الكود 
.focus-input:focus {
  border-color: #2563eb;
  box-shadow: 0 0 0 4px rgb(37 99 235 / 15%);
}
3

:focus-visible

تعرض مؤشر التركيز عندما يرى المتصفح أن إظهاره ضروري، وغالبًا عند التنقل بلوحة المفاتيح.

جرّب: استخدم زر Tab حتى تصل إلى الزر.

عرض الكود 
.keyboard-button:focus-visible {
  outline: 4px solid #f59e0b;
  outline-offset: 4px;
}
4

:active

تعمل في أثناء تفعيل العنصر، مثل لحظة استمرار الضغط على الزر.

جرّب: اضغط على الزر واستمر بالضغط.

عرض الكود 
.active-button:active {
  transform: scale(0.94);
  background-color: #166534;
}
5

:focus-within

يختار العنصر الأب عندما يحصل هو أو أي عنصر بداخله على التركيز.

جرّب: اضغط داخل الحقل ولاحظ إطار الصندوق كله.

عرض الكود 
.focus-within-box:focus-within {
  border-color: #2563eb;
  box-shadow: 0 0 0 4px rgb(37 99 235 / 15%);
}

ثالثًا

محددات النماذج

تتعامل مع حالة حقول الإدخال والاختيار.

13

:checked

يختار مربع الاختيار أو زر الراديو بعد تحديده.

عرض الكود 
.check-example input:checked + label {
  color: #15803d;
  font-weight: 700;
  text-decoration: line-through;
}
14

:disabled

يختار العناصر المعطلة التي لا يمكن للمستخدم التفاعل معها.

عرض الكود 
.disabled-input:disabled {
  background-color: #e2e8f0;
  color: #64748b;
  cursor: not-allowed;
  border-style: dashed;
}
15

:enabled

يختار الحقول والأزرار المتاحة وغير المعطلة.

عرض الكود 
.state-fields:enabled {
  border-color: #16a34a;
  background-color: #f0fdf4;
}

:required و:optional

الأول يختار الحقول الإلزامية، والثاني يختار الحقول الاختيارية.

عرض الكود 
.requirement-field:required {
  border-right: 5px solid #f97316;
}

.requirement-field:optional {
  border-right: 5px solid #64748b;

20 + 21

:valid و:invalid

يحددان ما إذا كانت قيمة الحقل صحيحة أو غير صحيحة حسب شروط HTML.

جرّب: اكتب بريدًا إلكترونيًا صحيحًا أو غير صحيح.

عرض الكود 
.validation-field:valid {
  border-color: #16a34a;
}

.validation-field:invalid {
  border-color: #dc2626;
}
رابعًا

المحددات المنطقية والروابط

تختصر المحددات أو تختار عناصر حسب محتواها وحالة الرابط.

20

:not()

يطبق التنسيق على العناصر ما عدا العناصر المطابقة للمحدد داخل الأقواس.

عرض الكود 
.not-buttons button:not(.current) {
  background-color: #e2e8f0;
  color: #64748b;
}
21 + 22

:link و:visited

:link للرابط الذي لم تتم زيارته، و:visited للرابط الذي تمت زيارته.

افتح رابطًا تجريبيًا
عرض الكود 
.links-example a:link {
  color: #2563eb;
}

.links-example a:visited {
  color: #7e22ce;
}
23

:is()

تختصر قائمة من المحددات بدل تكرار القاعدة نفسها.

عنوان داخل box-one

عنوان داخل box-two

عنوان داخل box-three

عرض الكود 
:is(.box-one, .box-two, .box-three) h4 {
  color: #be123c;
}
24

:where()

تشبه :is()، لكن قوة التحديد الخاصة بها تساوي صفرًا، لذلك يسهل تجاوز تنسيقها لاحقًا.

فقرة داخل where-card

فقرة داخل where-box

عرض الكود 
:where(.where-card, .where-box) p {
  background-color: #f1f5f9;
  padding: 12px;
}
25

:has()

يختار العنصر اعتمادًا على وجود عنصر محدد بداخله أو بجواره.

منتج عادي

السعر: 50 شيقل

منتج عليه خصم

السعر: 40 شيقل

خصم خاص
عرض الكود 
.product:has(.discount) {
  border-color: #dc2626;
  background-color: #fef2f2;
}
26

:root

يمثل العنصر الجذري للصفحة، وهو غالبًا عنصر html. يستخدم كثيرًا لتعريف متغيرات CSS العامة.

هذا الصندوق يستخدم متغيرات معرفة داخل :root.
عرض الكود 
:root {
  --primary-color: #7c3aed;
  --primary-soft: #f5f3ff;
}

.root-demo {
  color: var(--primary-color);
  background-color: var(--primary-soft);
}
27

:target

يختار العنصر الذي يطابق المعرّف الموجود بعد علامة # في عنوان الصفحة.

فعّل العنصر المستهدف
أنا العنصر المستهدف.
عرض الكود 
.target-box:target {
  border-color: #f59e0b;
  background-color: #fffbeb;
  transform: scale(1.01);
}
خامسًا

العناصر الزائفة Pseudo-elements

تستهدف أجزاء افتراضية من العنصر وتكتب غالبًا بنقطتين.

1

::before و::after

يضيفان محتوى تجميليًا قبل محتوى العنصر أو بعده. غالبًا نستخدم معهما الخاصية content.

عرض الكود 
.cart-button::before {
  content: "🛒";
}

.cart-button::after {
  content: " ←";
}
تطبيق

إنشاء Tooltip بواسطة ::before و::after

يُستخدم ::before لصندوق النص، و::after للمثلث الصغير.

عرض الكود 
.tooltip-button::before {
  content: attr(data-tooltip);
  /* بقية تنسيقات صندوق التلميح */
}

.tooltip-button::after {
  content: "";
  /* رسم المثلث باستخدام الحدود */
}
2

::first-letter و::first-line

الأول ينسق الحرف الأول، والثاني ينسق السطر الأول من النص.

هذا النص يمثل بداية مقال عن تصميم واجهات المستخدم. يمكن لتفاصيل صغيرة في CSS أن تغير شكل الموقع بالكامل وتجعله أكثر وضوحًا وجاذبية للمستخدم.

عرض الكود 
.article-text::first-letter {
  font-size: 2.4rem;
  color: #dc2626;
}

.article-text::first-line {
  font-weight: 700;
}
3

::selection

يغير تنسيق النص عندما يحدده المستخدم بالماوس.

حدّد هذا النص بالماوس لتلاحظ تغير لون الخلفية ولون الخط.

عرض الكود 
.selection-text::selection {
  background-color: #facc15;
  color: #111827;
}
4

::placeholder

ينسق النص الإرشادي المؤقت داخل حقل الإدخال.

عرض الكود 
.email-input::placeholder {
  color: #7c3aed;
  font-style: italic;
}
5

::marker

ينسق علامات القوائم، مثل النقاط والأرقام.

  • تعلم HTML لتنظيم المحتوى.
  • تعلم CSS لتنسيق الصفحة.
  • استخدم JavaScript لإضافة التفاعل.
عرض الكود 
.marker-list li::marker {
  color: #9333ea;
  font-size: 1.4rem;
}
8

::file-selector-button

ينسق الزر الداخلي الخاص بحقل رفع الملفات.

عرض الكود 
.file-input::file-selector-button {
  border: 0;
  padding: 10px 16px;
  background-color: #2563eb;
  color: white;
}
9

::backdrop

ينسق الخلفية التي تظهر خلف نافذة dialog المنبثقة.

نافذة Dialog

الخلفية الداكنة خلف النافذة تم تنسيقها بواسطة ::backdrop.
عرض الكود 
dialog::backdrop {
  background-color: rgb(15 23 42 / 70%);
  backdrop-filter: blur(3px);
}
