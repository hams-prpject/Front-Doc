WHY FLEXBOX

لماذا Flexbox؟

قبل Flexbox كان تخطيط الصفحات كابوساً. الآن الأمور مختلفة تماماً.

قبل Flexbox

  • استخدام float و clear بطرق معقدة
  • توسيط العناصر عمودياً يتطلب أكواداً هاكية
  • ترتيب العناصر يتطلب تغيير HTML
  • توزيع المسافات يدوياً ومعرض للأخطاء
  • عدم استجابة تلقائية لأحجام الشاشة

مع Flexbox

  • تخطيط أحادي البعد بسيط وواضح
  • توسيط أفقي وعمودي بسطر واحد
  • إعادة ترتيب بصري بدون لمس HTML
  • توزيع مسافات تلقائي ومرن
  • استجابة طبيعية مع flex-wrap

HOW IT WORKS

آلية العمل

فهم المحاور هو المفتاح الأساسي لإتقان Flexbox

المحور الرئيسي (Main Axis)

الاتجاه الذي يتم فيه ترتيب العناصر المرنة. يكون أفقالياً بشكل افتراضي (من اليمين لليسار في RTL). يبدأ من main-start وينتهي عند main-end.

المحور العرضي (Cross Axis)

المحور العمودي على المحور الرئيسي. يبدأ من cross-start وينتهي عند cross-end. يُستخدم لمحاذاة العناصر عمودياً.

عند تغيير flex-direction تتغير اتجاهات المحاور معاً. فهم هذا المفهوم يمنع الالتباس.

Flex Container
العنصر الأب الذي يملك display: flex
Flex Items
الأبناء المباشرون داخل الحاوية
Main Size
عرض أو طول العنصر على المحور الرئيسي
Cross Size
عرض أو طول العنصر على المحور العرضي
CONTAINER PROPERTIES

خصائص الحاوية (الأب)

تُطبق على العنصر الذي يحتوي display: flex

01

display: flex

الخاصية الأساسية التي تحول العنصر إلى حاوية مرنة. كل الأبناء المباشرون يصبحون عناصر flex تلقائياً.

1
2
3
.container {
  display: flex;
}
02

flex-direction

يحدد اتجاه المحور الرئيسي وبالتالي كيفية ترتيب العناصر.

1
2
3
4
.container {
  display: flex;
  flex-direction: row;
}

/* row: افتراضي، أفقي */
/* row-reverse: أفقي معكوس */
/* column: عمودي */
/* column-reverse: عمودي معكوس */

03

flex-wrap

يحدد ما إذا كان العناصر ستنتقل لسطر جديد عندما لا تتسع المساحة أم سيتم ضغطها.

1
2
3
4
5
.container {
  display: flex;
  flex-wrap: nowrap;
}

/* nowrap: كل العناصر في سطر واحد (افتراضي) */
/* wrap: الانتقال لسطر جديد عند الحاجة */
/* wrap-reverse: عكس اتجاه الانتقال */
04

justify-content

يتحكم بتوزيع المسافات على المحور الرئيسي. هذه من أكثر الخصائص استخداماً.

1
2
3
.container {
  display: flex;
  justify-content: flex-start;
}

05

align-items

يتحكم بمحاذاة العناصر على المحور العرضي (المحاور العمودية في التخطيط الأفقي).

1
2
3
4
.container {
  display: flex;
  align-items: flex-start;
}

/* stretch: يمد العناصر لملء الحاوية (افتراضي) */
/* flex-start: بداية المحور العرضي */
/* flex-end: نهاية المحور العرضي */
/* center: توسيط على المحور العرضي */
/* baseline: محاذاة حسب خط النص */
06

align-content

يتحكم بتوزيع المسافات بين الأسطر (يحتاج flex-wrap: wrap). يختلف عن align-items الذي يتعامل مع العناصر داخل السطر.

1
2
3
4
5
6
.container {
  display: flex;
  flex-wrap: wrap;
  align-content: stretch;
}

تنبيه: align-content لا يؤثر عندما يكون flex-wrap: nowrap لأنه لا توجد أسطر متعددة.

07

gap

يحدد المسافة بين العناصر المرنة. أسهل بكثير من استخدام margin على كل عنصر.

1
2
3
4
5
6
.container {
  display: flex;
  flex-wrap: wrap;
  gap: 10px 10px;
}

/* القيمة الأولى: المسافة العمودية */
/* القيمة الثانية: المسافة الأفقية */
/* قيمة واحدة = مسافة متساوية في كلا الاتجاهين */

خصائص العناصر (الأبناء)

تُطبق على العناصر الفرعية داخل الحاوية المرنة للتحكم بسلوك كل عنصر على حدة

order

/* لا يؤثر على ترتيب القراءة أو التبويب */
02

flex-grow

يحدد مقدار قدرة العنصر على التوسع لملء المسافة الفارغة. القيمة الافتراضية هي 0 (لا يتوسع).

0

.item-1 { flex-grow: 0; }
.item-2 { flex-grow: 0; }
.item-3 { flex-grow: 0; }

/* grow:1 يتوسع بالتساوي */
/* grow:2 يأخذ ضعف المساحة */
/* التوزيع يحدث نسبياً */
03

flex-shrink

يحدد مقدار قدرة العنصر على التقلص عندما لا تتسع المسافة. القيمة الافتراضية هي 1 (يتقلص). ضعه 0 لمنع التقلص.

1

3
.item-1 { flex-shrink: 1; }
.item-2 { flex-shrink: 1; }
.item-3 { flex-shrink: 1; }

/* 0 = لا يتقلص أبداً */
/* 1 = يتقلص بالتساوي (افتراضي) */
/* العناصر الأكبر تتقلص أكثر */
04

flex-basis

يحدد الحجم الافتراضي للعنصر قبل توزيع المساحة الفارغة. يشبه width/height لكنه أكثر دقة في سياق Flexbox. القيمة الافتراضية هي auto.

.item-2 { flex-basis: 80px; }
.item-3 { flex-basis: 80px; }

/* auto: يستخدم حجم المحتوى أو width */
/* يمكن استخدام px, %, em, rem */
/* يتجاوز width عند وجوده */
05

flex (الاختصار)

اختصار لثلاث خصائص: flex-grow flex-shrink flex-basis

flex: 0 1 auto
القيمة الافتراضية
flex: 1
flex: 1 1 0% - الأكثر استخداماً
flex: none
flex: 0 0 auto - ثابت الحجم
/* الصيغة الكاملة */
.item { flex: <grow> <shrink> <basis>; }

/* أمثلة شائعة */
.item { flex: 1; } /* 1 1 0% */
.item { flex: 0 0 200px; } /* ثابت 200px */
.item { flex: 2 1 100px; } /* يتوسع بضعف البقية */
.item { flex: auto; } /* 1 1 auto */
06

align-self

يتجاوز align-items لعنصر واحد فقط. نفس القيم المتاحة. يسمح بمحاذاة مختلفة لكل عنصر.

1
2
3
4
.container {
  display: flex;
  align-items: center;
}

.target {
  align-self: auto;
}

/* auto: يتبع align-items */
/* القيم الأخرى: تتجاوز align-items */
