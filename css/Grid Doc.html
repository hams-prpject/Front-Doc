WHY GRID

لماذا CSS Grid؟

أول نظام تخطيط ثنائي الأبعاد في CSS. مصمم خصيصاً لبناء التخطيطات المعقدة

متى نستخدم Grid ومتى نستخدم Flexbox؟

CSS Grid

  • تخطيط الصفحة الكلية (layout)
  • هياكل ثنائية الأبعاد (صفوف + أعمدة)
  • عندما تحتاج محاذاة عناصر في اتجاهين
  • تصاميم مجلات وبطاقات معقدة
  • عندما تحتاج مناطق مسماة

CSS Flexbox

  • مكونات واجهة صغيرة (components)
  • هياكل أحادية البعد (صف أو عمود)
  • قوائم تنقل وأزرار ومدخلات
  • توسيط عنصر واحد بسرعة
  • توزيع مسافات في اتجاه واحد

القاعدة الذهبية: Grid للتخطيط الكلي، Flexbox للمكونات الداخلية. يمكن استخدامهما معاً — Grid في الخارج و Flexbox في الداخل.

HOW IT WORKS

آلية العمل

فهم المصطلحات الأساسية هو الأساس لبناء أي تخطيط بشبكة

خطوط الشبكة (Grid Lines)

الخطوط غير المرئية التي تقسم الشبكة. تُرقم تبدأ من 1. يمكن استخدامها لتحديد مكان العناصر. الخطوط السلبية تُعد من النهاية (-1 = آخر خط).

المسارات (Tracks)

المسافة بين خطين متجاورين. يمكن أن تكون أعمدة (columns) أو صفوف (rows). تحدد بـ grid-template-columns و grid-template-rows.

الخلايا والمناطق (Cells & Areas)

الخلية = تقاطع صف وعمود. المنطقة = مجموعة خلايا مسماة تُستخدم لتخطيط مرئي واضح مثل "header" أو "sidebar".

CONTAINER PROPERTIES

خصائص الحاوية (الأب)

تُطبق على العنصر الذي يحتوي display: grid

01

display: grid

يحول العنصر إلى حاوية شبكية. كل الأبناء المباشرون يصبحون عناصر grid.

1

.container {
  display: grid;
}
02

grid-template-columns

يحدد عدد الأعمدة وعرض كل عمود. يدعم وحدات fr و px و % و minmax() و repeat().

1
2
3
4
5
6
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

/* fr = جزء من المساحة المتاحة */
/* repeat(عدد, حجم) = تكرار */
/* minmax(أدنى, أعلى) = مدى مرن */
/* auto-fill = يملأ تلقائياً */
03

grid-template-rows

يحدد عدد الصفوف وارتفاع كل صف. يعمل بنفس طريقة الأعمدة.

1
2
3
4
5
6
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: auto auto;
}

/* auto = يتكيف مع المحتوى */
/* إذا زادت العناصر عن الصفوف */
/* تُنشأ صفوف إضافية تلقائياً */
04

grid-template-areas

يسمح بتسمية المناطق بصرياً ورسم تخطيط الصفحة كنص. من أقوى خصائص Grid.

Header
Sidebar
Main Content
Aside
Footer
.container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
  grid-template-rows: 60px 1fr 50px;
  grid-template-areas:
    "header header header"
    "sidebar main aside"
    "footer footer footer";
}

.header { grid-area: header; }

08

justify-content / align-content

يحددان موقع الشبكة ككل داخل الحاوية عندما تكون الشبكة أصغر من الحاوية. يختلف عن justify/align-items التي تتعامل مع العناصر داخل خلاياها.

1
2

  display: grid;
  grid-template-columns: 100px 100px;
  justify-content: start;
  align-content: start;
}

/* يعملان عندما الشبكة */
/* أصغر من الحاوية */
/* place-content: اختصار لهما */
09

grid-auto-flow

يحدد كيفية وضع العناصر التي لم تُحدد مكانها بشكل صريح. row (افتراضي) يملأ بالصفوف، column يملأ بالأعمدة، dense يملأ الفراغات.

/* مفيد مع عناصر span مختلفة */

ITEM PROPERTIES

خصائص العناصر (الأبناء)

تُطبق على العناصر الفرعية للتحكم بوضعها وامتدادها داخل الشبكة

01

grid-column / grid-row

يحدد موقع وامتداد العنصر باستخدام خطوط الشبكة. grid-column: start / end و grid-row: start / end. يمكن استخدام span لتحديد عدد الخلايا.

العنصر البرتقالي (2) — جرّب القيم المختلفة:

1
2
3
4
5
6
7
8
9
.item-2 {
  grid-column: auto / auto;
  grid-row: auto / auto;
}

/* start / end = رقم خط البداية والنهاية */
/* span N = يمتد N خلايا */
/* -1 = آخر خط (خطوط سالبة) */

/* اختصارات: */
/* grid-column: 2 = يبدأ عند خط 2 */
/* grid-column: 2 / span 2 */
02

grid-area

اختصار لتحديد row-start / column-start / row-end / column-end دفعة واحدة. أو يمكن استخدامه مع grid-template-areas لربط العنصر باسم المنطقة.

  grid-area: header;
}
03

justify-self

يتجاوز justify-items لعنصر واحد. يتحكم بمحاذاة العنصر أفقياً داخل خليته.

/* place-self: align-self justify-self */
04

align-self

يتجاوز align-items لعنصر واحد. يتحكم بمحاذاة العنصر عمودياً داخل خليته.

1
2 (هدف)

}
05

place-self

اختصار لـ align-self و justify-self. مثال: place-self: center = توسيط مثالي للعنصر في خليته.

.item {
  place-self: center center; /* توسيط في الخلية */
  place-self: end start; /* أسفل اليمين */
  place-self: stretch; /* يملأ الخلية */
}
